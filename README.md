# Fantasy-Pudding（奇幻世界 布丁）

《瑪奇Mobile》非官方輔助工具（適用於港澳台版）

---

## 📥 下載與安裝

### 1. 必備前置環境（初次使用請先安裝）
本工具需要封包擷取驅動支援，請先下載並安裝 Npcap：
* **Npcap 下載**：[點此下載 Npcap 1.88 安裝檔](https://npcap.com/dist/npcap-1.88.exe)  
  *(安裝時建議使用預設設定即可)*

### 2. 下載本工具
請至右側的 [Releases 頁面](../../releases) 下載最新版本的壓縮包或執行檔，解壓縮後即可使用。

---

## 🚀 使用說明

1. 確認電腦已安裝 **Npcap**。
2. 啟動遊戲《瑪奇Mobile》。
3. 執行 `Fantasy-Pudding.exe`。
4. 工具將自動擷取網路封包並顯示輔助資訊。
